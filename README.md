# Voice Agent


## Installation


```bash
    brew install pyenv 
    brew install pyenv-virtualenv
    pyenv install python 3.12.13
    pyenv virtualenv 3.12.13 voice-agent
```
```bash
    cd VoiceAgent
    pyenv local voice-agent
    pip install -r requirements.txt
    python main.py 
```
